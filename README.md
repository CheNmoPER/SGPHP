# SGPHP

一个高性能的 PHP 加密工具，支持 SourceGuardian 与 IonCube 两大主流加密方案，为 PHP 源码提供专业级的保护。

## 支持的加密方案

### SourceGuardian
- SourceGuardian 14
- SourceGuardian 15
- SourceGuardian 16

### IonCube
- IonCube 11
- IonCube 12
- 更多版本持续支持中

## 特性

- **高性能**：加密后代码执行效率不受明显影响
- **兼容性强**：支持多个加密版本，适配不同运行环境
- **保护全面**：防止源码泄露、逆向工程与二次分发
