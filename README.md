# SGPHP

SGPHP 是一款面向 PHP 开发者的源码加密与保护工具，支持 **SourceGuardian** 与 **IonCube** 两大主流商业加密方案。通过字节码级别的混淆与加密，为 PHP 应用程序提供可靠的代码保护，有效防止源码泄露、逆向分析与非法二次分发。

## 功能特性

- **多方案支持**：同时兼容 SourceGuardian 与 IonCube 两套加密体系，覆盖主流商业授权场景
- **高性能表现**：加密后的代码经优化处理，对运行性能的影响降至最低
- **强兼容性**：适配多种加密版本与运行环境，满足不同部署要求
- **完善保护**：具备防调试、防篡改与授权绑定能力，全方位守护源码安全

## 常见问题

**加密后代码无法运行？**
请确认运行环境已安装与加密方案匹配的扩展，且扩展版本不低于加密时所用的版本。

**可以混合使用两种加密方案吗？**
同一套代码建议统一采用一种加密方案，以保证运行环境的配置一致性。

更多问题可前往官网文档或通过 Issue 提交反馈。
